Como ler os exemplos

comando -opção argumento: o comando é a ferramenta; a opção muda seu comportamento; o argumento é o alvo, como arquivo, usuário ou porta. Nem todo parâmetro começa com hífen.

Os arquivos e hosts dos exemplos são fictícios e devem ser substituídos pelos seus. Comandos de criação, extração e renomeação alteram arquivos; o guia apenas exibe texto, sem executar comandos. Para consultar todas as opções instaladas na sua máquina, use man nome-do-comando ou nome-do-comando --help quando disponível.

Os níveis indicam quando o recurso apareceu nas suas anotações ou como alternativa relacionada. Não é preciso usar todas as ferramentas para resolver o jogo.

Base: suas anotações do Bandit. Parâmetros escolhidos para o que você já estudou; este guia não tenta reproduzir os manuais completos. Atualização: 13/10/2026.
